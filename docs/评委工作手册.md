# 评委工作手册

> 配套文件：《人力资源部新委员选拔标准》。评委须在评分培训时通读本手册，正式评分前完成签到与回避情况申报。

## 一、评委的角色

你代表人力资源部对报名人员进行专业、客观的评价。你的每一份评分表都将被留存、复核，并直接决定录取结果。请做到：**对标准负责、对事实负责、对每一位报名人员负责。**

## 二、评分前

1. 参加评分培训，熟悉 9 个评分维度、满分权重和四档行为锚定；
2. 确认本场面试形式（初试/复试）、每人时长、提问分工；
3. 申报回避情形：与报名人员有亲属、恋爱、同班、同宿舍等密切关系的，主动向组长报告；
4. 手机静音，领取评分表和题本，不得拍照、外传。

## 三、面试中

1. **先听事实，再下判断**：关注报名人员讲述的具体事例（任务—行动—结果），而非口号和自我评价；
2. 提问按分工进行，不打断、不追问隐私、不设诱导性或刁难性问题；
3. 每名报名人员面试结束后 **当场独立打分**，不与其他评委商量，不修改他人评分；
4. 分数应落在对应维度满分范围内，建议先定档（优秀/良好/合格/不合格），再在档内给具体分；
5. 加分项须核实佐证材料，同一经历不重复加分，最高 5 分；
6. 发现迟到、敷衍等减分情形或弄虚作假等一票否决情形的，在备注栏写明事实。

## 四、常见评分误差（请主动避免）

| 误差 | 表现 | 纠正方法 |
|---|---|---|
| 首因效应 | 被开场 30 秒的印象左右整场评分 | 每个维度独立判断，记录事实 |
| 光环效应 | 因某一项突出（如口才好）就全项打高分 | 逐维度对照行为锚定分别打分 |
| 趋中倾向 | 不敢打高分、低分，全部给 75–80 | 确有突出/不足时敢于拉开差距 |
| 对比误差 | 受前后报名人员表现影响 | 以统一标准而非相互比较来评分 |
| 与我相似 | 偏爱专业、籍贯、爱好与自己相近的人 | 只按岗位要求评价 |
| 刻板印象 | 对性别、专业、年级等想当然 | 只看当场表现与事实材料 |

## 五、评分尺度参考（以满分 15 分维度为例）

- 优秀（13.5–15）：表现突出、有事例，明显超出岗位要求；
- 良好（11–13）：表现较好、达到要求；
- 合格（9–11）：基本达标、表现一般；
- 不合格（9 以下）：存在明显短板。

> 其他满分维度按相同系数折算：优秀 90%–100%、良好 75%–89%、合格 60%–74%、不合格 60% 以下。

## 六、面试后

1. 核对评分表：维度无漏项、分数无超范围、合计正确，签字交工作人员；
2. 不向报名人员透露评分情况，不私自许诺录取结果；
3. 配合监督人员对异常分差（与同场平均分相差 15 分以上）的复核；
4. 对选拔过程中接触的个人信息严格保密，选拔结束后不得留存报名人员材料。

## 七、纪律红线

- 不得接受请托、馈赠，不得串通打分、篡改分数；
- 不得隐瞒应回避关系；
- 不得泄露题目、评分和个人隐私；
- 违反上述纪律的，取消评委资格，并按组织有关规定处理。
