# 人力资源部新委员选拔标准

> 一套面向**学生组织（学生会 / 社团 / 团委）人力资源部**的新委员（干事）招新选拔完整方案：制度文档 + 公开网页 + 表格模板 + 评分计算器，开箱即用。

## ✨ 项目特点

- **完整闭环**：覆盖「公告 → 报名 → 资格审查 → 笔试（可选）→ 初试 → 复试 → 录取审议 → 公示 → 试用 → 转正」全流程；
- **标准量化**：9 个评分维度 + 加分项，满分 100+5 分，每个维度均有四档行为锚定，评委尺度统一；
- **公开可查**：自带 GitHub Pages 网页，任何同学都能公开查看标准、流程与申诉渠道；
- **工具配套**：报名表、面试评分表、成绩汇总表、试用期考核表模板齐全，Excel / WPS 直接打开；
- **交互算分**：网页内置评分计算器，自动校验分数、按规则去最高 / 最低分并给出录取建议；
- **纪律保障**：含评委回避、独立打分、监督复核、异议申诉、一票否决等公信力机制。

## 🚀 快速开始

### 直接使用

1. 打开公开网页（GitHub Pages 部署后）查看完整标准，或直接阅读 [`docs/人力资源部新委员选拔标准.md`](docs/人力资源部新委员选拔标准.md)；
2. 下载 `templates/` 下的表格，按当期招新名额修改后打印 / 线上发放；
3. 组织评委学习 [`docs/评委工作手册.md`](docs/评委工作手册.md)，统一评分尺度；
4. 面试现场使用网页「评分计算器」快速统分。

### 本地预览网页

无需任何依赖，双击 `index.html` 即可在浏览器打开；或在项目目录启动一个本地服务：

```bash
# 任选其一
python -m http.server 8000
npx serve .
```

然后访问 <http://localhost:8000>。

## 📌 标准要点速览

**评分维度与权重（面试 100 + 5 分）**

| 维度 | 满分 | 维度 | 满分 |
|---|---|---|---|
| 思想品德与责任心 | 15 | 组织协调与执行潜力 | 10 |
| 语言表达与沟通能力 | 15 | 文档与办公技能 | 10 |
| 逻辑思维与应变能力 | 15 | 时间精力与稳定性 | 10 |
| 求职动机与岗位认知 | 10 | 仪容仪表与精神面貌 | 5 |
| 团队协作与服务意识 | 10 | 加分项（经验 / 特长） | 5 |

**综合成绩构成**

- 设笔试：`笔试 30% + 初试 30% + 复试 40%`
- 不设笔试：`初试 40% + 复试 60%`

**关键规则**

- 录取合格线不低于 **70 分**，名额不足时减少名额、不降格录取；
- 评委 ≥ 5 人时去掉 1 个最高分、1 个最低分后平均；
- 拟录用名单公示 **3 个工作日**，异议 3 个工作日内核查答复；
- 试用期 **4 周**，考核合格后正式录用建档；
- 弄虚作假、舞弊、隐瞒重要事实等情形**一票否决**。

## 🌐 部署到 GitHub Pages（公开访问）

1. 将本仓库推送到 GitHub（仓库设为 **Public**）；
2. 仓库页面依次进入 `Settings → Pages`；
3. `Build and deployment → Source` 选择 **Deploy from a branch**；
4. `Branch` 选择 `main` 分支、目录为 `/ (root)`，保存；
5. 等待约 1 分钟，页面顶部即出现公开访问地址：
   `https://<你的用户名>.github.io/<仓库名>/`。

## 🔧 自定义适配

本项目是通用模板，各组织可按需调整，**调整内容须在招新公告中一并公布**：

- 岗位方向：修改 `index.html` 岗位表格与制度文档第三章；
- 维度权重：同步修改 `docs/人力资源部新委员选拔标准.md` 第五章、`index.html` 权重板块，以及 `assets/js/main.js` 顶部的 `DIMS` 数组；
- 合格线、公示期、试用期：修改制度文档对应条款与网页文案；
- 组织名称 / Logo：替换网页 Hero、页脚中的名称。
